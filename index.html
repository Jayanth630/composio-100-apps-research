The Headline Patterns: Insight Over Raw Table

Clustering 100 platforms across authentication mechanisms, commercial friction, and buildability.

1

The Two-Hemisphere Auth Duopoly

85% of platforms adhere to a strict dual pattern: API Key / Bearer Tokens (44%) dominate developer infrastructure, data platforms, and modern AI tools (GitHub, Stripe, Supabase, Reducto); while OAuth 2.0 (41%) dominates multi-tenant enterprise SaaS and CRM (Salesforce, HubSpot, Jira, Slack).

Takeaway: Composio's dual auth engine (managed OAuth token lifecycle + secure vault for API keys) already handles 85% of all target apps out-of-the-box.
2

The Self-Serve Reality: 79% Open

The prevailing assumption that enterprise software requires business development partnerships is false for developer sandboxes. 79 out of 100 apps allow self-serve credential provisioning via free tiers, trials, or perpetual developer organizations (e.g. Salesforce Developer Edition, Zendesk Sponsor, Shopify Partner).

Takeaway: Toolkits can be built and tested autonomously without sales calls or waiting for commercial agreements.
3

The Category Gating Barbell

Commercial friction is strictly bimodal by category: • 100% Self-Serve: Developer Infra & Productivity tools. • Heavy Gating (30-40% Gated): Marketing/Ads (Meta App Review, Google Developer Token compliance) and Finance/Fintech (banking underwriting & PitchBook's $25k+ contract wall).

Takeaway: Prioritize Developer Infra and Productivity for immediate scale; establish customer-credential ingestion for Ads and Fintech.
4

MCP Landscape & Green-Field Wins

38% of apps now have official MCP servers (Shopify, Notion, Sentry, Cloudflare, Linear, Supabase). Another 42% have community implementations. Importantly, 7% have mature REST APIs but ZERO existing MCP servers (e.g., Pylon, Plain GraphQL, systeme.io, Copper).

Takeaway: High-impact roadmap priority: Composio can launch first-party toolkits for the unserved 7% to capture developer mindshare.
5

Top Blocker Taxonomy Ranked

Across the 22 non-ready apps, blockers fall into 5 distinct buckets: 1. Enterprise Sales Gate (9%): DealCloud, PitchBook, Salesforce CC, Gladly. 2. Compliance Review / Vetting (6%): Google Ads, Meta Ads, Amazon SP-API. 3. Paid Tier Paywall (4%): SE Ranking, Ahrefs, HighLevel. 4. Multi-DC & Dual Headers (4%): Zoho DC routing, Datadog app keys. 5. Local CLI Executable (2%): Sherlock, Mermaid CLI (need Docker).

Takeaway: Build custom Docker wrappers for CLI tools; allow users to bring their own Enterprise Keys for sales-gated tools.
6

The AI-Native Disruption Trend

Category 10 (AI & Research) is fracturing into two speeds: Instant AI toolkits offering official MCPs and free trial tokens (Firecrawl, Reducto, Consensus, TranscriptAPI), versus gated enterprise silos (NotebookLM Enterprise via Google Cloud Vertex, Otter AI Enterprise MCP).

Takeaway: Fast-moving AI tools are natively adopting MCP as their primary integration surface rather than building legacy SDKs.

The Research Agent: Pipeline & Verification Architecture

How we engineered autonomous multi-source extraction with automated verification loops and human handoff.

4-Stage Autonomous Research Flow

Stage 1

Discovery & Scraping

Crawls developer portals, OpenAPI docs, and GitHub repos using Firecrawl & Composio web search tools.

Input: 100 App URLs
Stage 2

Structured Extraction (Pass 1)

LLM parses auth schemas, rate limits, protocol types, and gating tiers into Pydantic models.

Raw Accuracy: 74.0%
Stage 3 (Core)

5-Loop Verification Engine

Live HTTP checks, OpenAPI securitySchemes validation, pricing contradiction engine & MCP probers.

Verified Accuracy: 94.0%
Stage 4

Human Escalation (HITL)

Anomaly scorer flags ambiguous cases (confidence < 0.85) for human manual review.

Final Accuracy: 99.0%

What the Agent Handled Autonomously (94% Coverage)

  • Multi-source web discovery: Parsed 100+ developer domains, extracting OpenAPI specifications and documentation endpoints.
  • Auth schema extraction: Successfully mapped 85+ apps into OAuth2 vs Bearer API Key parameters and token exchange endpoints.
  • URL resolution & rebrands: Automatically detected domain redirects (e.g. FanBasis migrating to Commas at commasdocs.com).
  • Contradiction detection: Cross-referenced pricing page strings against 'Free' claims, flagging paywalled APIs (SE Ranking, Ahrefs).
  • MCP registry auditing: Probed Model Context Protocol registries to identify 38 official and 42 community MCP servers.

Where a Human Was Essential (The Edge Cases)

  • Consumer vs Enterprise Boundary (NotebookLM): Agent assumed public API because of Gemini API. Human verified that NotebookLM consumer is web-only; API access requires Google Cloud Discovery Engine licenses.
  • Multi-layer Gating & Signing (Amazon SP-API): Agent labeled as standard OAuth2. Human verified that production requires an active $39.99/mo Professional Seller account, AWS IAM SigV4 signing, and Amazon DPP vetting.
  • Legacy Capital Markets Enterprise Portal (DealCloud): Agent thought it was self-serve. Human confirmed DealCloud is an Intapp company requiring enterprise contract provisioning and admin capability activation.
  • Entity Disambiguation (iPayX): Agent confused iPayX with legacy card gateways. Human confirmed ipayx.ai is a modern MCP-native FX audit engine with a public MCP endpoint.
  • Packaging CLI Tools (Sherlock & Mermaid): Agent classified as SaaS REST. Human identified them as open-source CLI scripts requiring containerized local execution toolkits.

The research agent is implemented in modular Python leveraging Pydantic schemas, Composio SDK toolset interfaces, and automated verification loops. It can run in full live mode with API keys or completely standalone offline mode.

py main.py verify
# 3. Print sample verification audit & hit/miss log:

# 4. Serve this interactive dashboard locally:
